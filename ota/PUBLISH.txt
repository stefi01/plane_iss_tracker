Buyers do not use Arduino. They use SETUP > ABOUT on the 7 in screen.

The chip flashes a .bin (Arduino export). It does not flash an Intel .hex.

1. In the sketch, set your GitHub user next to HFS_VER:
     #define HFS_GH_USER "stefi01"
     #define HFS_GH_REPO "plane_iss_tracker"
   Bump HFS_VER (ota/version.txt must be that same number).

2. Tools must stay:
     ESP32S3 Dev Module, OPI PSRAM, 16MB,
     Partition Scheme  16M Flash (3MB APP/OTA)

3. Sketch > Export compiled Binary.
   The file lands next to the sketch as:
     Final_3.5.ino.esp32s3.bin
   Rename a copy to:
     ota/hfs_7in.bin

4. ota/version.txt is one line: 3.6

5. On GitHub, in repo plane_iss_tracker on branch main, upload:
     ota/version.txt
     ota/hfs_7in.bin
   The bin must be an export of the sketch after HFS_VER is 3.6.
   Do not upload ota/Final_3.5.ino.esp32s3.bin as that file.
   The desk already running 3.5 can tap CHECK, then INSTALL.
   A desk that was just USB-flashed as 3.6 will say this is the latest.

No GitHub yet: copy the .bin to the SD card root as HFS.BIN.
On the screen: SETUP > ABOUT > FROM SD. Do not unplug while it writes.
